# Proposal: Initialize Vanilla Web App with Atomic Design, Tokens, and Tailwind CSS v4

## Context
Create a foundation for a modern web application leveraging native web technologies (HTML5, Vanilla CSS, Vanilla JavaScript ES modules) combined with modern styling ergonomics via Tailwind CSS v4 and the Atomic Design methodology.

## Objectives
1. Provide a clean, scalable directory structure based on Atomic Design (Atoms, Molecules, Organisms, Templates).
2. Implement a single source of truth for design tokens (colors, typography, spacing, elevation) defined in native CSS variables and exposed to Tailwind CSS v4 `@theme`.
3. Support ultra-fast development and optimized zero-overhead bundling via Vite.
4. Deliver a live showcase in `index.html` demonstrating the system in action.
