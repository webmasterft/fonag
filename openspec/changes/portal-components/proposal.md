# Proposal: Core Portal Components (Header, Hero & Cifras del Portal)

## Context
Implement the 3 primary visual sections of the FONAG SEDC portal:
1. Top navigation header with brand logo, active route indicator, and login action.
2. Mountain watershed hero section with SEDC brand lockup, description, and floating search capsule.
3. "Cifras del Portal" interactive metric cards grid (4 categories with icons, counters, and call-to-actions).

## Objectives
- Integrate with registered brand palette (`#242857` Navy, `#f19001` Orange, `#41a6e5` Blue).
- Enforce max container width of `1366px`.
- Adhere to Atomic Design taxonomy and pure Vanilla CSS/JS.
