# Proposal: Add FONAG Footer Organism

## Motivation
Establish the official corporate footer for FONAG based on brand guidelines and provided design specs.

## Proposed Solution
Implement the footer as an organism composed of modular atoms and molecules, registered into the existing design tokens and Tailwind CSS v4 pipeline.

## Deliverables
1. Design tokens update (footer background, orange accent, divider opacity).
2. Atomic CSS classes and semantic HTML structure.
3. Accessible SVGs for social channels (Facebook, X, Instagram, TikTok) and the FONAG logo.
4. Mobile-responsive layout behavior.
