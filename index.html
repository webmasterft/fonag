FONAG v1.0 • SDD
Spec-Driven Development + Atomic Architecture

Clean Foundation with Vanilla Web & Tailwind v4

Built with pure semantic HTML5, Vanilla CSS Design Tokens, decoupled Vanilla JS ES modules, and native Tailwind CSS v4 theme integration.

01. Design Tokens

Core Layer

Centralized tokens defined in src/css/tokens/ for colors, typography, spacing, and elevation. Interoperable with Tailwind v4 @theme.

CSS Variables + @theme

02. Atomic Elements

Primitives

Self-contained single-responsibility atoms including interactive button variants with dynamic ripple effects, inputs, and badge chips.

src/css/atoms

03. Molecules

Compositions

Composed functional units such as real-time search inputs with debounce/clear controls and responsive metric card layouts.

Filterable Live

04. Organisms

High-level UI

Autonomous UI blocks including the glassmorphism header navigation bar, persistent theme controller, and hero banner.

Stateful Controls

05. Tailwind v4 Loop

Build Engine

Zero-config CSS-first engine using Vite plugin without legacy JS config files, generating instant utilities alongside vanilla styles.

@tailwindcss/vite Fast HMR

06. Spec-Driven Dev

Methodology

Every step tracked through formal OpenSpec artifacts under openspec/changes/init-app/: Proposal, Spec, Design, and Tasks.

OpenSpec Standard
